# 🧮 Score Calculator

A powerful desktop score calculator with **voice input**, **statistics**, **Excel export**, **undo/redo**, and **multi‑language support** (French, Arabic, English).  
Specially designed for adding numbers with fractions and keeping track of running totals.

![Python](https://img.shields.io/badge/python-3.7+-blue.svg)
![PyQt5](https://img.shields.io/badge/PyQt5-5.15-green.svg)
![License](https://img.shields.io/badge/license-MIT-lightgrey.svg)

## ✨ Features

- **Basic arithmetic** – enter numbers via keyboard, mouse or voice
- **Fraction buttons** – 0.25, 0.5, 0.75 for quick input
- **Two history tables**:
  - Editable number history (double‑click to modify)
  - Saved totals history (one‑click saving)
- **Undo / Redo** (Ctrl+Z / Ctrl+Y) – go back any number of steps
- **Voice recognition** (French, Arabic, English) using [Vosk](https://alphacephei.com/vosk/)
- **Export to Excel** (.xlsx) with both histories in one sheet
- **Statistics** – mean, standard deviation, line plot and histogram
- **Multi‑language UI** – French, Arabic (RTL), English
- **Keyboard & mouse shortcuts** – see Help menu

## 📦 Requirements

- Python 3.7 or higher
- Windows / Linux / macOS (a working microphone for voice input)
